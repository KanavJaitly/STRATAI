# Phase 6 — P6-M0 decision log

**Status:** revision 1, 2026-10-04 (specification defined; **not frozen**). The spec is `docs/P6Milestones.md`.

**Two kinds of entry:**
- **Ambiguity resolutions (P6-A\*):** places where the authoritative documents (`docs/ROADMAP.md`, `docs/PROJECT_VISION.md`, `prompts/MASTER_BUILD.md`), or those documents and the existing Phase 4/5 contracts, can be read more than one way. Each records the selected resolution and why. They are **proposed**: Kanav approves or overrides them at P6-M0.
- **Open decisions (P6-Q\*):** methodological choices and thresholds that no project document fixes. MASTER_BUILD's escalation rules forbid choosing them silently. Each lists options and a **proposed default, which is not a decision**. Each must be decided by Kanav **before the affected result exists**. P6-M0 freezes when every P6-Q is decided, or explicitly deferred to a named milestone with a "decide before" point.

Nothing here changes a Phase 4 or Phase 5 decision, criterion or record. D9 applies throughout: a genuine failure stops and escalates, and no methodology is changed after a result to manufacture a pass.
