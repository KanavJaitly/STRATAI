## Decisions — DECIDED (Sven Morais, 2026-10-17)

| P7-Q1 | **Alliance selection: a truthful locked contract and the engine's real refusal.** Lock the full selection response shape. Serve candidate profiles (P6-M6 factors, INTERIM caveat). The pick list runs only with an approved P6-M1 ruleset for the event and passing PX-1 (P6-Q3), PX-2 (P6-Q4) and PX-4 (P6-Q5) gates, with `probability_status = "validated_playoff"` only when the PX-4 record's `passed` is true (as `scripts/phase6_playoff_track.py` sets it). Otherwise it returns the real refusal: a `RulesetError` code (`not_approved`, `storage_integrity`, `wrong_season`, `event_excluded`, `not_covered`, and from `ml.playoffs.selection`: `not_established`, `not_supported`, `infeasible`, `invalid_state`, `event_rules_required`), or one **new** API code, `playoff_models_not_accepted` (409), when the PX gates have not passed. Check order and gate source: R4. P7-DM1 reports alliance selection (and playoff-context strategy odds) as **"callable, refusal only; real output deferred with P6-DM1"**, with refusal-only examples, never as plainly met | No real selection output is claimed while its rulesets and models are unapproved. The shape is locked before Phase 8. P6-M1, P6-A12 and the 2026-10-17 acceptance record are respected |
| P7-Q2 | **Rankings: the event-analysis ordering is canonical; the M12 ranking route is deprecated, not removed.** `GET /events/{event_key}/analysis` ordering (P5-D6 policy: raw EPA before the switch point, M5 v2 after) is the canonical rankings surface. `GET /predictions/events/{event_key}/ranking` stays, behaviour and label (`moderate_held_out`) unchanged, marked `deprecated` in OpenAPI and documented as non-canonical, with the reason.
